# docs 索引

本目录分两层：**活文档**（描述当前代码，需随代码更新）与 **archive/**（历史快照，只读，不再维护）。

判断标准只有一条：**它描述的是「现状」还是「某个时间点的想法」**。前者要准，错了就是坑；后者不准也无所谓，动它反而是伪造历史。

## 归档约定

- 归档即 `git mv`，不删文件——历史要能从 git 里翻出来，也要能直接打开看。
- 归档文件**不再修改**。若发现其中某条仍然有效且有价值，摘进活文档，原文不动。
- 新增审查报告：当前有效的放本目录，**全部条目修完后**移入 archive。避免 docs 根下堆一串「不知道还算不算数」的报告。
