规格要点（对应文档 §4.1）
  • 触发：GET /api/libraries 返回空 → 显示本引导卡
  • 库名校验：非空、≤32 字符、唯一；失败在输入框下方提示
  • 「链接 iCloud 照片库」→ POST /api/libraries 建库（状态 pending）→ 进入认证视图（②）

  • 点击「开始全量拉取」→ POST /api/library/:id/sync {kind: full}，进入主界面显示进度

规格要点（对应文档 §3.1.1，自绘方案）
  • 后端 spawn icloudpd --username <邮箱> --password-provider console --mfa-provider console --domain cn --auth-only；密码、验证码由前端两步输入经 POST /api/library/:id/auth/input 写入子进程 stdin
  • 状态机：pending → waiting_input → linked / failed；成功判据 = 进程退出 + cookie 落盘
  • 密码/验证码仅驻留内存、不进后端日志；10 分钟无进展 → kill 并提示重试
  • 官方 webui 方案（--password-provider webui，已实测可用）保留为备选

规格要点（对应文档 §4.2 / §4.3）
  • 同步操作区在现有 resource-status 下拉组件内扩展，不重构既有 UI；全量/增量二选一互斥，选择后出现「执行 / 取消」，执行中带状态动画，可中途取消
  • 每库同时仅 1 个下载任务；认证过期时此处变「需要重新链接」入口（expired）
  • 右上角「我的相册 ▾」：点击列出全部库、点击切换；切库 = 整页初始化（滚动位置/已加载状态全清，用户决策）
  • 切换后端流程：停当前库任务 → 关连接 → 激活新库 → 前端刷新（切换事务，防串库）

规格要点（对应文档 §4.4）
  • 库列表带「当前」标识（当前激活库）；每库卡片提供全量/增量同步操作，与主界面同款「二选一 → 执行/取消 → 状态动画」

  • 参数按库保存（libraries.icloudpd_args），切库后各库配置独立
